# 🤖 Plataforma Multiagente - Garimpo Network (Agente Rafinha)

Plataforma enxuta e de alta performance focada na prospecção, atendimento e qualificação comercial de Agentes de IA via WhatsApp.

## 🚀 Tecnologias Utilizadas
* **Node.js / TypeScript** (Backend corporativo)
* **Express** (Gerenciamento de rotas e webhooks)
* **Google Gemini API (`gemini-1.5-flash`)** (Motor de Inteligência Artificial com Mega Prompt restrito)
* **Evolution API** (Gateway de integração com o WhatsApp)
